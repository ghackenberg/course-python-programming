# Programming with Python

![](./Images/Social_Preview_169.jpg)

This repository contains the comprehensive materials for the **Programming with Python** course, including presentation slides, exercise sheets, and multiple-choice tests. The course is designed to provide students with a solid foundation in Python programming, covering everything from basic syntax to advanced topics like object-oriented design, data analysis, and web integration.

The following table provides a detailed overview of the curriculum and direct links to the individual session materials:
